【改写方法论（必须遵守）】
第 1 步：从原简历的每个项目/经历中提炼事实——项目是什么、你做了什么、用了什么方法/工具、有哪些数字成果。
第 2 步：对照岗位职责与任职要求，找出可迁移到该岗位的能力点（如用户调研、需求分析、数据复盘、方案落地、跨团队协作）。
第 3 步：用岗位相关词汇重新组织表述，句式遵循「动词开头 + 背景/做了什么 + 方法工具 + 结果/量化」，但事实与数字必须全部来自原简历。
第 4 步：只改写原简历中真实存在的条目；原简历没有的条目一律不得新增（见硬约束）。

【对照示例：把科研项目讲成产品/运营语言（事实完全不变）】
原文：
一种纺织商品的全生命周期碳足迹测算方法和装置（负责人）
项目简介：针对电商平台个人碳计算器缺少"衣"的碳足迹、可选衣物少、页面单调的痛点，回收 171 份问卷显示 85.6% 大学生不使用现有系统、60% 表示增加趣味性后愿意使用；设计了男女双人物模型切换、衣物/城市选择等功能页面。

岗位化改写（目标：产品/运营方向）：
纺织商品碳足迹测算产品（负责人）｜2025.07-2025.08
用户调研：围绕"衣"的碳足迹场景回收 171 份有效问卷，定量定位 85.6% 大学生不使用现有个人碳计算器、60% 会因趣味化功能提升使用意愿，提炼"页面单调、可选衣物少"两大用户痛点。
产品方案：负责功能设计与交互规划——设计男/女双人物模型换装、衣物选择与发货/收货城市选择、结果页分阶段碳排放占比饼图，把问卷结论转化为提升工具吸引力与信息可读性的具体功能。
价值：以一手调研数据支撑产品决策，方案直接面向电商平台碳计算工具的用户体验优化。

注意：改写后依然只有原简历里真实存在的项目与数据，只是换了更贴合岗位的表述方式。

【硬约束（违反即失败）】
1. 严禁新增原简历没有的任何内容：实习经历、工作经历、公司、职位、时间段、项目、奖项、技能、证书、电话、邮箱、学校。
2. 若原简历没有「实习经历/工作经历」区块，改写后的简历也不得出现该区块或任何"曾在…实习/担任…"的表述。
3. base_city 只能照抄笔记中出现的城市，没有就填""；contact_email 笔记中没有就填""，严禁编造。
4. post_type 只能填 全职/实习/兼职/找继任 其中一个，无法判断填""。
5. 把岗位任职要求中的关键词（{keywords}）集中写入改写简历的「个人优势/专业技能」栏；
   正文项目描述可自然出现，不强制重复。
6. 简历区块顺序固定（自上而下）：姓名/求职意向/联系方式 → 教育经历 → 项目经历 →
   个人优势 → 专业技能 → 荣誉奖项；「个人优势/专业技能/荣誉奖项」必须放在简历最后，不得提前。
7. 荣誉奖项必须原样保留原简历中的奖项全称，不得改名、缩写或泛化
   （例如不得把「全国大学生数学竞赛非数A类湖北省三等奖」写成「数学竞赛获奖」）。
8. target_optimized_resume 必须是可直接排版的简历文本（分区标题 + 条目/要点），
   严禁输出 JSON、字典、键值对或任何形如 "姓名:…/教育经历:[…]" 的结构化字段；
   姓名、求职意向、联系方式直接写成文本行即可。
9. 严禁虚构「期望在 XX 公司 / 期望入职 XX」等原简历与岗位笔记中都没有的表述。
10. job_name 只能取笔记文字中明确出现的岗位名；若笔记未写明岗位
    （如“JD 见 P2/图二/评论区”，岗位信息在图内），job_name 必须填 ""，
    严禁用目标岗位或其它笔记推断岗位名。
6. 输出 JSON 前不要写任何分析文字。

请只输出一个 JSON 对象（不要输出任何其他文字），字段如下：
- job_name：岗位名称
- base_city：工作城市
- contact_email：投递邮箱
- job_duty：岗位工作职责（从笔记提取）
- job_requirement：岗位任职要求（从笔记提取）
- post_type：全职/实习/兼职/找继任 或 ""
- resume_optimize_suggestion：简历优化思路；若想新增原简历没有的技能，必须在此列出并标注「需用户确认是否具备及熟练程度」
- target_optimized_resume：改写后的适配简历片段（事实全部来自原简历）
